# TryWorld Writer

**把内容写得像人写的。**

> 不模板化，不口号化，不灌水。目标是写出可发布、有判断、有细节的长文。

</div>

---

## 它能解决什么问题

- 需要写公众号、专栏、长文，但不知道从哪下手
- 需要观点清晰、细节完整、结构可交接的文章
- 不想只拿到一个看起来完整的草稿，而是拿到真正可发布的版本

---

## 适用场景

- AI 相关深度文章
- 专栏稿和公众号长文
- 从 brief、PDF、链接、资料生成长文
- 需要个人风格、观点表达和可交付输出

---

## 输入

- 文章主题、资料、brief、PDF、链接
- 用户想要表达的判断或经历
- 目标读者和文章调性
- 是否需要批注修改、扩写、提炼转述

---

## 输出

- 强观点、有细节、可发布的文章
- 结构化成文稿或完整长文
- 可继续修改的批注版或精修版
- 面向发布的长文成品或素材包

---

## 工作流摘要

1. 理解资料与表达目标
2. 判断观点是否足够清晰
3. 提炼信息、补足证据和细节
4. 组织成文，控制篇幅与节奏
5. 输出成品或仍保留修改空间，按用户需要交接

---

## 快速开始

```bash
cd skills/tryworld-writer
```

直接查看该目录下的 `SKILL.md`，按说明执行写作流程。

---

## 与其他 Skills 的关系

- 研究结论可交给 Writer 灌入文章
- 技术内容可先用 `tryworld-paper-algorithm` 拆解，再写文章
- 产品/公司/行业研究可先用 `tryworld-hv-analysis`，再交给 Writer
- 选题结果可先用 `tryworld-koubo-selection`，再用 Writer 成稿
