# TryWorld HV Analysis

**横向对比 × 纵向追踪：把研究对象看清楚**

> 研究不是堆资料，而是把信息变成可检查的结构化结论。

</div>

---

## 它能解决什么问题

- 需要研究一个产品、公司、行业、人物、技术方向
- 需要一份有结构、有关键判断、可交付的研究结论
- 信息很多，但容易散，需要被整理成可复查的版本

---

## 适用场景

- 竞品与研究对象的深度分析
- 行业机会点和风险判断
- 技术或商业概念的长期演变梳理
- 为选题、内容或商业决策提供资料支撑

---

## 输入

- 产品、公司、行业、人物、概念、技术名称
- 研究目标和重点维度
- 可公开获取的资料来源
- 他希望重点回答的问题

---

## 输出

- 结构化研究结论
- 横向对比与纵向时间线
- 关键证据、来源和判断依据
- 可直接转成 PDF 的研究简报

---

## 工作流摘要

1. 明确研究对象与研究目标
2. 联网收集权威和一手信息
3. 做横向比较与纵向演变分析
4. 汇总结论、证据和风险点
5. 输出为可直接交付的研究文档

---

## 快速开始

```bash
cd skills/tryworld-hv-analysis
```

直接查看该目录下的 `SKILL.md`，按步骤执行研究工作流。

---

## 与其它 Skills 的关系

- 研究结论可作为 `tryworld-koubo-selection` 的选题依据
- 研究信息可交给 `tryworld-writer` 形成深度文章
- 技术类研究结论可继续进入 `tryworld-paper-algorithm` 拆解成视频内容
