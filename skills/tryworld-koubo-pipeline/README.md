# TryWorld Koubo Pipeline

**从选题到成片清单：内容生产的交付流水线**

> 不追求“完美选题”，追求可执行、可检查、可复用的内容生产 SOP。

</div>

---

## 它能解决什么问题

- 只有一个模糊方向，不知道怎么落地成内容
- 需要明确选题、脚本、封面、发布说明
- 需要减少反复，直接进入生产流程

---

## 适用场景

- AI 视频选题与脚本生产
- 从 raw idea 到发布前检查清单
- 中轻度提升成片质量，而不重写整套流程
- 需要把 paper/分析结果转化为可传播内容

---

## 输入

- 选题方向或原始素材路径
- 是否要一起做优化和出图
- 用户可接受的脚本风格和平台规则
- 是否需要输出发布计划

---

## 输出

- 选题清单与单题说明
- 结构化脚本
- 平台标题建议
- 成片检查清单与交付说明
- 封面、话题、发布时间建议

---

## 工作流摘要

1. 判断输入模式：只做选题 / 只做脚本 / 完整 pipeline
2. 执行选题或脚本生成
3. 优化表达与结构
4. 输出封面标题、平台说明和发布建议
5. 返回可交付成果，等待用户确认后再继续下一级内容生产

---

## 快速开始

```bash
cd skills/tryworld-koubo-pipeline
```

直接查看该目录下的 `SKILL.md`，按模式执行。
