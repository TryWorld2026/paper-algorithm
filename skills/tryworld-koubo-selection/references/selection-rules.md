# 试界TryWorld 口播选题规则

## 频道定位

- 试界TryWorld · 纸上算法风格：AI 科普 / 教程 / 内容解读，受众是普通人（非技术创业者、设计师、普通读者）。
- 视频约 10 分钟以内；口播稿超长先提炼核心。
- 数据必须真实可查：每个数据点带来源，无法核实标"待核实"，不编造。

## 增长第一性原理（标题与选题的核心依据）

| 目标 | 原理 | 在选题中的体现 |
|---|---|---|
| 流量 | 有共鸣的选题内容 | 反常识、痛点、好奇；开头即"与我有关" |
| 点赞 | 内容认可 | 有硬数据、专业判断、清晰逻辑，不夸大 |
| 评论 | 制造槽点 | 留一个可争论、可反驳、开放的问题 |
| 转发 | 给人当嘴替 | 替观众说出想说不会说的话，观点鲜明 |
| 涨粉 | 价值认同 | 有方法论 / 系列感 / "以后用得上" |

## 选题筛选清单（逐条过）

1. 有钩子吗：反常识结论 / 悬念问题 / 硬数字冲击，能撑起 0-15 秒开场？
2. 有数据吗：至少 1-2 个可核实的数据点或案例，带原文链接？
3. 普通人能懂吗：术语有"人话翻译"，回答"所以呢 / 跟我有什么关系"？
4. 会重复吗：查 `done-topics.md`，避开已做选题（同模型 / 同主题换角度也算）。
5. 命中原理吗：至少命中 1-2 个增长原理，标注是哪个。

## 输出模板（选题清单）

```markdown
# AI 口播选题（<YYYY-MM-DD> 数据窗）

### 1. <选题名>（优先级：高/中/低）
- 为什么选：<命中原理 + 一句话理由>
- 核心素材：<2-4 条，每条含标题 + 原文链接>
- 切入角度：<2-3 句，含开场钩子建议>
- 命中：共鸣 / 认可 / 槽点 / 嘴替 / 价值认同
```

## 可选进阶

- 用户选中选题后：给出稿骨架（开场钩子 → 3-5 层结构 → 结论/收尾），或直接转入 `$tryworld-paper-algorithm` 完整流程（核实数据 → 优化稿 → 确认 → 配音出片）。
- 周更栏目：固定每周拉一次数据做"本周 AI 圈盘点"，保持系列感。
