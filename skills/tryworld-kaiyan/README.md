# 试界开言 TryWorld Kaiyan

把选题或素材写成中文短视频口播稿。只交付文字，不做封面、配音、分镜、渲染或视频合成。

## 用法

在对话里说“试界开言，写口播稿”，或者直接给一个主题、链接、新闻和素材。没有主题时，Skill 会先拉 AIHOT 最近 7 天精选，给出 3 到 5 张选题卡并停下等选择。

完整写稿包包含七部分。

1. 选题卡
2. 事实来源表
3. 主稿
4. 视频标题，包括主标题和四个平台标题
5. 抖音、视频号、小红书、B站的开头和收尾变体
6. 三类轻提示
7. 自检报告

普通人指非技术岗位的上班族、大学生和刚进入社会的年轻人，以及接触过 AI 但不是从业者、不是大佬、不是行业精英的人。选题和写稿都不要求读者追 AI 新闻、写代码或懂模型。

## 质检与标题

写稿包必须依次通过五道闸门，不能只跑机器检查。

1. **事实**：数字、日期、价格、能力、身份和引语都能回到来源表；官方说明不写成实测，计划不写成已开放。
2. **字面**：检查器没有硬伤；冒号、破折号、黑话、模型路标、翻案句和总结腔清零。
3. **口播**：一句话一口气说得完；长句拆开，代词有明确对象，出声读一遍不绕舌。
4. **普通人**：术语有预算，第一次出现能解释；每段回答“跟我有什么关系”，不看 AI 新闻的人也能复述核心判断。
5. **对抗式**：普通观众、事实核查员和流量编辑分别攻击，再由反方主理人反驳核心判断；回应不了就缩小判断或补证据。最后由同一主理人分角色完成，不声称启动了多个模型。

标题短优先，标点算字，空格不计。主标题及小红书、B站标题不超过 8 个字符；抖音和视频号不超过 6 个字符。这些是本项目内部上限，不冒充平台官方规则。每次先按六种角度生成 12 个候选，留 5 个互相攻击，再由流量编辑、普通观众和品牌主理人分角色评分，最后按吸引力、准确性、普通人相关性和字数合规做加权选择。

## 品牌开场与收尾

主稿默认开头写“哈喽，我是TryWorld。”，控制在 2 秒内，然后立刻接原来的钩子。主稿末尾在具体判断或行动之后写“我是TryWorld，下次见。”。

- 抖音、小红书：保持冷开场，开头不加品牌签名；收尾加固定签名。
- 视频号、B站：开头先写“哈喽，我是TryWorld。”再接原钩子；收尾加固定签名。
- 四个平台的共同规则：签名放在行动之后，不抢开头 5 秒的冲突，也不替代具体判断。

“哈喽大家好，欢迎来到我的频道，今天我们聊聊……”这类长开场不建议使用，也不进入标准交付。用户坚持时先说明它会拖慢钩子，标成人工例外；短版、抖音和小红书不用。

## 工具

拉取 AIHOT v1 最近精选。

```text
python scripts/fetch_topics.py --days 7 --take 100
```

脚本默认把 ETag 和响应体缓存在 `state/http-cache.json`，下次请求带 `If-None-Match`，收到 304 时直接复用缓存。需要持续轮询时：

```text
python scripts/fetch_topics.py --days 7 --take 100 --watch --interval 60
```

`--interval` 不能小于 60 秒；`--no-cache` 可禁用缓存。

检查纯主稿文本。

```text
python scripts/check_script.py <file> --title "视频标题" --platform master|douyin|shipinhao|xiaohongshu|bilibili [--short] [--json]
```

退出码 `0` 表示没有硬伤，`1` 表示需要修改，`2` 表示输入或参数错误。

## 边界

AIHOT 只用于发现线索。重要事实回到发布方原文。对外商业产品、公开镜像或批量再分发 AIHOT 数据前，需要确认使用授权。
