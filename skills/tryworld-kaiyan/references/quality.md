# 质量闸门

## 使用原则

五道闸门按顺序执行，不能跳，也不能用其中一道的结果代替另一道。

对抗式审查由同一个试界主理人切换角色完成。可以分别以普通观众、事实核查员、流量编辑和反方主理人的身份提问，但不要声称真的启动了多个模型、多个外部专家或独立评审团。

每一轮修改后，重跑受影响的闸门。交付前必须完整跑完五道闸门和 100 分评分卡。机器检查通过不等于稿子成立。

## 第一闸，事实

### 检查项

- 主稿里的每个数字、日期、价格、产品能力、开放范围、身份和引语，都能在事实来源表找到对应行。
- 每个关键断言标明强度，只能是已确认、官方说法、合理推断、未能确认之一。
- 官方说法没有写成独立实测，计划没有写成已经开放，部分用户没有写成所有人。
- 用户没有提供的个人经历，没有写成“我试过”。
- 来源之间冲突时，主稿采用更保守的表述，或明确写出无法确认。
- 核心判断依赖的关键事实找不到原文时，停止写稿，不靠语气补足。

### 输出格式

| 项目 | 结果 |
|---|---|
| 结论 | 通过 / 失败 |
| 关键断言数 |  |
| 有来源覆盖 |  /  |
| 断言强度分布 | 已确认 条；官方说法 条；合理推断 条；未能确认 条 |
| 过度断言 |  |
| 未解决事实 |  |
| 处理动作 | 删除 / 缩小 / 补来源 / 保留并降级表述 |

只要核心断言无来源、官方说法被写成实测、或仍有未解决事实，事实闸门失败。

## 第二闸，字面

### 检查项

- 把主稿单独保存为纯正文文件，运行字面检查器。
- 全文字数在对应区间内。主稿 550 到 800 个汉字，短版 300 到 450 个汉字。
- 冒号、破折号、硬停词、绝对黑话、模型路标、翻案句和总结腔清零。
- 0 到 2 秒的短品牌签名“哈喽，我是TryWorld。”是允许的开场，不算问候硬伤。
- 除短签名外的问候、自我介绍和频道介绍算硬伤，尤其是长版欢迎语“哈喽大家好，欢迎来到我的频道，我是TryWorld，今天我们聊聊……”，以及任何把钩子拖到 5 秒之后的问候。
- 标准交付没有长版欢迎语例外。用户坚持时先说明代价并标成人工例外，检查器仍会判硬伤；60 秒短版、抖音、小红书更不能用。
- 标题单独检查字符数，并核对是否与主稿承诺一致。
- 警告不能只看数量，要逐条判断是否影响口播或可信度。

### 输出格式

| 项目 | 结果 |
|---|---|
| 命令 | `python scripts/check_script.py <主稿文件> --title "<主标题>" --json` |
| 退出码 | 0 / 1 / 2 |
| 汉字数 |  |
| 预估时长 |  |
| 硬伤 | 条，逐条列行号和原文 |
| 警告 | 条，逐条写保留理由或修改动作 |
| 标题字符数 |  |

退出码为 1 时，硬伤必须清零。退出码为 2 表示路径或参数错误，不能当成通过。硬伤未清零，字面闸门失败。

## 第三闸，口播

### 检查项

- 主理人真实出声读一遍，不用默读代替。
- 开头使用短品牌签名时，“哈喽，我是TryWorld。”必须在 0 到 2 秒内说完，说完立刻进入钩子；第 5 秒前必须出现冲突、代价或反常识钩子。
- 品牌签名不能拖成长版频道介绍；抖音、小红书默认冷开场，不先念品牌签名。
- 固定收尾使用“我是TryWorld，下次见。”或“我是TryWorld，下次见，拜拜。”，不加问号，且放在具体判断或行动之后。
- 一句话一口气说不完的地方，拆开或换语序。
- 连续三句都很短、像口号的地方，合并或展开一句。
- 每个“它、这个、那件事”都能在前一句找到明确对象。
- 数字和专有名词不绕舌，术语第一次出现能用普通话接住。
- 长句超过 40 个汉字时，确认不是把两个判断塞在一起。
- 读起来像文章、需要回看上一句才能懂的地方，重写。

### 输出格式

| 问题位置 | 原文 | 读起来的问题 | 改后 | 是否复读 |
|---|---|---|---|---|
| P2 |  | 换气不顺 / 指代不明 / 绕舌 / 书面语 |  | 是 / 否 |

另记品牌签名实际时长、钩子出现时间、实际朗读时长和预估时长，差异超过 15 秒时说明原因。签名超过 2 秒、钩子晚于 5 秒、固定收尾加了问号，或仍有必须停下来重读的句子，口播闸门失败。

## 第四闸，普通人

### 检查项

- 受众是不是具体的非技术岗位上班族、大学生或刚进入社会的年轻人，而不是“所有人”。
- 一个不看 AI 新闻、不写代码的人，能不能复述这条视频的核心判断。
- 开头 2 秒内是否完成品牌签名，5 秒内是否已经听到钩子；长版欢迎语是否被误用。
- 术语有没有超过预算，第一次出现有没有用普通话解释。
- 抽象名词有没有换成具体动作、场景或后果。
- 每个关键事实后面有没有回答“所以跟我有什么关系”。
- 是否出现居高临下、教训观众、行业精英口吻或假装亲历。
- 今天能做的事是否具体，不需要再查一堆背景。
- 固定署名是否放在具体判断或行动之后，是否没有替代结论。

### 输出格式

| 检查问题 | 是 / 否 | 证据或问题句 |
|---|---|---|
| 能说出具体普通人是谁 |  |  |
| 能复述唯一核心判断 |  |  |
| 开头 2 秒内完成签名、5 秒内出现钩子 |  |  |
| 术语在预算内且有解释 |  |  |
| 关键信息都有普通人后果 |  |  |
| 结尾有今天能做的动作或判断 |  |  |
| 没有专家腔或假经历 |  |  |

只要普通人相关性不成立、核心判断无法复述、钩子晚于 5 秒、品牌签名拖成长版欢迎语，或术语负担明显超过预算，普通人闸门失败。

## 第五闸，对抗式审查

### 第一轮，三角色各至少 3 条

每条问题必须包含位置、具体问题、对观众或可信度的影响、修改建议。禁止只写“整体不错”“可以更自然”“再打磨一下”。

#### 普通观众

- 哪一句听不懂，为什么。
- 哪一段想划走，信息增量是什么。
- 哪一句和我有什么关系，没讲清楚。
- 听完能不能用自己的话复述核心判断。

#### 事实核查员

- 哪句话没有来源。
- 哪句话把官方说法写成了独立实测。
- 哪个数字没有基数、时间或范围。
- 哪句话在假装亲历、内部消息或专家身份。
- 哪个推断超出了证据能支撑的边界。

#### 流量编辑

- 开头 5 秒有没有具体冲突、代价或反常识结论。
- 开头 2 秒内是否完成品牌签名；有没有把“哈喽大家好，欢迎来到我的频道……”拖到钩子前面。
- 中段每一段有没有继续听下去的新理由。
- 结尾有没有先给具体判断或动作，再给固定署名；署名有没有替代结论。
- 标题是否准确兑现了主稿承诺。
- 哪里像广告、通报或行业报告，观众会失去兴趣。

### 第二轮，反方主理人至少 4 个攻击

反方主理人不是挑错字，而是攻击核心判断是否成立。至少回答以下四项。

1. 这个判断最强的反例是什么。
2. 现有证据能不能支撑到这一步，哪一步是作者自己加的。
3. 哪类普通人会觉得这条视频跟自己无关，为什么。
4. 如果把判断缩小一半，会不会更可信，应该删掉哪一部分。

作者必须逐条回应。回应只能是四类动作：

- 接受并修改。
- 补充来源或案例。
- 缩小判断范围。
- 删除无法支撑的段落。

不能只写“已注意”或“保留观点”。攻击成立但稿子没有变化，视为未回应。

### 输出格式

| 轮次 | 角色 | 具体问题 | 位置 | 严重度 | 作者回应 | 修改动作 | 复检 |
|---|---|---|---|---|---|---|---|
| 1 | 普通观众 |  | P1 | 高 / 中 / 低 |  |  | 通过 / 未通过 |

第一轮至少 9 行，三个角色各 3 行。第二轮至少 4 行攻击，每一行都要有回应和修改动作。

### 最多自动修改 3 轮

- 第一轮修改后，至少重跑字面、口播和普通人闸门。
- 第二轮修改后，重跑事实和对抗审查。
- 最多自动修改 3 轮。第 3 轮仍不通过，停止改稿。

没有通过时，明确告诉用户卡在哪一类。

- 事实缺口，需要补原文、数据或用户实测。
- 结构问题，核心判断太多或证据撑不住。
- 口播问题，句子无法自然开口。
- 普通人问题，受众、后果或行动不成立。
- 标题问题，候选无法准确兑现主稿承诺。

说明下一步需要补什么，不硬交稿，不把“待确认”藏在成稿里。

## 100 分评分卡

每一项按整数打分，总分 100。总分低于 80，不得交付。任一硬闸门失败，即使总分超过 80，也不得交付。

| 维度 | 分值 | 满分标准 | 常见扣分 |
|---|---:|---|---|
| 钩子 | 15 | 0 到 5 秒给出具体冲突、代价或反常识结论，对象清楚；品牌签名不超过 2 秒 | 长版欢迎语、背景铺垫、抽象口号、标题与开头脱节 |
| 单一判断 | 15 | 全文只证明一个可被反驳的判断，每段都服务它 | 两个以上判断、事实罗列、结尾换题 |
| 证据 | 20 | 两到三个有效证据，来源和限制准确，断言强度匹配 | 只有二手摘要、数字无基数、官方说法写成实测 |
| 边界 | 15 | 写清谁不适用、什么没开放、哪里仍不确定，并影响行动 | 空泛免责声明、只讲好处、把可能写成已经 |
| 口播顺滑 | 15 | 出声可读，长句能换气，指代清楚，术语在预算内 | 文章句、绕舌、连续短句、术语堆叠 |
| 人格 | 10 | 第一人称、有判断、有取舍，不装专家、不装亲历 | 营销腔、专家腔、训人、假故事 |
| 结尾 | 10 | 给出与正文一致的具体判断或动作，再放固定署名，不重复总结 | 空泛号召、强行点赞关注、署名替代结论或抢在判断前 |
| 合计 | 100 | 80 分及以上，且五道硬闸门全部通过 |  |

## 交付判定

只有同时满足以下条件，才能进入最终交付。

- 五道闸门全部通过。
- 第一轮至少 9 条具体问题，第二轮至少 4 个攻击，全部有回应。
- 100 分评分不低于 80。
- 字面检查退出码为 0，硬伤清零。
- 品牌签名不超过 2 秒，钩子在 5 秒内出现，长版欢迎语未被误用。
- 固定署名在具体判断或行动之后，没有替代结论，也没有加问号。
- 标题通过字数、准确性和普通人相关性检查。
- 没有未解决的事实缺口，没有假经历，没有标题过度承诺。

任何一项不满足，状态写“未通过”，列明卡点和下一步所需材料。机器检查通过不等于稿子成立。
