Paper Algorithm · 纸是舞台，墨是表达，朱红是重点，印章是签名

试界 TryWorld · Codex Skills 合集

五个技能，一条内容生产线：选题、写稿、出片、深度研究、公众号写作。
每个技能独立可用，合在一起便是一套完整的 AI 口播工作流。

你把需求说成一句话，系统判断直接出片还是先做选题，再自动交付可发布的内容产物与配套材料。

技能 Skills #

01

tryworld-koubo-pipeline

口播统一入口 · 自动路由

一句人话即可启动；自动识别给稿模式与选题模式，支持子命令、成品去重与交付后邮件通知。

产出 全流程交付 · 邮件通知 依赖 其余技能 · qq-email
02

tryworld-paper-algorithm

纸上算法视频制作

口播稿优化净化、云希配音、HyperFrames 构图渲染，再输出横竖封面、平台标题与字幕；印章全程常驻。

产出 主视频 · 封面 · 标题 依赖 HyperFrames · edge-tts · FFmpeg
03

tryworld-koubo-selection

AI 资讯选题

从 AIHOT 最新动态筛选可做选题，附角度、素材原文链接与优先级，并自动避开已生产内容。

产出 3-8 个候选选题 依赖 AIHOT API · PowerShell / curl
04

tryworld-hv-analysis

横纵分析法深度研究

纵轴还原事物发展轨迹，横轴比对同类格局，交叉提炼关键洞察，最终输出 PDF 研究报告。

产出 PDF 研究报告 依赖 Python · WeasyPrint · Markdown
05

tryworld-writer

公众号长文写作

把 PDF、链接、语音转写、简报等素材整理成具备叙事节奏和阅读落点的公众号长文。

产出 长文成品 依赖 —

工作流 Workflow #

flowchart LR
    U(["一句话"]) --> P["tryworld-koubo-pipeline"]
    P -- "模式 A · 直接给稿" --> A["tryworld-paper-algorithm
优化 → 确认 → 出片"]
    P -- "模式 B · 帮我选题" --> S["tryworld-koubo-selection
AIHOT 资讯 → 选题清单"]
    S -- "你挑选" --> A
    A --> O["成片交付
视频 · 封面 · 标题 · 发布计划"]
    O -. "自动" .-> M["邮件通知
产物 + 四平台发布时间"]

口播链路只需记住一个入口：$tryworld-koubo-pipeline。研究型和写作型任务则可独立调用。
