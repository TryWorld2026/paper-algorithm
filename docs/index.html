试界 TryWorld · Codex Skills 合集

五个技能，一条内容生产线：选题、写稿、出片、深度研究、公众号写作。
每个技能独立可用，合在一起便是一套完整的口播工作流。

技能 Skills

01

tryworld-koubo-pipeline

口播统一入口 · 自动路由

一句人话，自动走选题或直接出片；子命令；去重；成片交付后自动邮件通知。

产出 全流程交付 · 邮件通知  ·  依赖 其余技能 · qq-email
02

tryworld-paper-algorithm

纸上算法视频制作

口播稿 → 云希配音 → HyperFrames 构图渲染 → 封面、标题、字幕；印章全程常驻。

产出 主视频 · 封面 · 标题  ·  依赖 HyperFrames · edge-tts · FFmpeg
03

tryworld-koubo-selection

AI 资讯选题

从 AIHOT 最新动态筛值得做的选题，带角度、素材链接与优先级；自动避开已做选题。

产出 3-8 个候选选题  ·  依赖 AIHOT API
04

tryworld-hv-analysis

横纵分析法深度研究

纵轴追生命历程，横轴比竞品格局，交叉出独到洞察，产出精美 PDF 报告。

产出 PDF 研究报告  ·  依赖 Python · WeasyPrint
05

tryworld-writer

公众号长文写作

把 PDF、链接、语音转写、简报等素材，写成试界风格的公众号长文。

产出 长文成品  ·  依赖 —
