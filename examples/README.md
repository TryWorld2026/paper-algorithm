# examples · 效果展示

本目录存放由本仓库技能端到端产出的真实示例，无人工后期修改。唯一例外：`cursor-spacex` 口播稿第 1 行标题的中文冒号在本仓库公开前替换为逗号，以通过活人感门禁检查；语义与朗读不变。

具体包含：

- **视频**：`preview_720p.mp4` 为 720p 预览版（ffmpeg 重编码，便于克隆仓库）；原片为 1080p、约 30-45MB，存放在本地工作区。
- **封面**：横版 4:3（1920x1440）与竖版 3:4（1080x1440），深墨海报视觉，与视频画面两套语言。
- **titles.txt**：3-5 个平台标题候选，标注推荐平台与命中增长原则；同受活人感门禁约束。
- **口播稿**：经「优化 → 活人感改稿七遍 → 硬禁项清零」后的最终成稿。
- **发布计划.txt**：四平台推荐发布时间。

| 示例 | 主题 | 时长 | 预览大小 |
|---|---|---|---|
| [cordis-paper](cordis-paper/) | DeepSeek 论文精读：把拆插件讲成数学 | 8.8 分钟 | 12 MB |
| [cursor-spacex](cursor-spacex/) | SpaceX 买下 Cursor | 6.6 分钟 | 8 MB |
